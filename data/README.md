# Dataset Setup

The raw mock census dataset is not included in this repository.

Place the census dataset under:

```text
data/raw/
```

The analysis expects demographic fields covering areas such as age, household information, marital status, gender, occupation, religion and infirmity.

Before running the notebook, update the data-loading cell if necessary so that it points to your local dataset. Running Jupyter from the repository root is recommended for consistent relative paths.
